# Profits Circle Trader — Ultimate Day Trading Platform

Profits Circle Trader is a modern, client-heavy, serverless day trading platform designed for day traders who want professional-grade trade journaling, analytics, position size calculation, and risk management.

## Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Shadcn/UI dark mode design
- **Icons**: Lucide React
- **Charts**: Recharts (Account Equity Curve & Analytics)
- **State Management**: Zustand
- **Deployment**: GitHub Pages via GitHub Actions

## Core Features (Phase 1 MVP)
- **Trade Journal**: CRUD trade logging (Symbol, Asset Class, Direction, Entry/Exit, Size, Stop Loss, Target, P&L, Setup Type, Quality Score, Emotion Tags, Notes)
- **Dashboard**: Live KPIs (Total Net P&L, Win Rate, Profit Factor, Average Win/Loss Ratio, Interactive Cumulative Equity Curve)
- **Position Size Calculator**: Calculates lot sizes, position notional value, maximum risk amount, and Risk/Reward Ratio for Crypto, Forex, and US Stocks.
- **User Profile & Settings**: Configure starting capital, default risk per trade %, and preferred timezone.
